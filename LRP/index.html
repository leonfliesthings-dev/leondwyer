Understanding Your Requirements

What You Asked For

We've studied your Product Requirements Document in detail. The core need is clear: transform client-supplied KML/SHP boundaries into optimised, flight-ready polygons with integrated GCP planning and field navigation — for large-scale projects exceeding 1,000 hectares.

Automated Grid Generation

Transform boundary files into overlapping flight polygons with configurable cell sizes, shapes, and overlap margins. Handle irregular boundaries with intelligent clipping.

Flight Feasibility Engine

Real-time assessment of flight time, battery usage, and operational safety per polygon. Colour-coded visual feedback: green (safe), orange (marginal), red (exceeds limits).

GCP & CHK Planning

Automated ground control point placement at grid vertices and polygon centres, with manual refinement. Check point placement for quality assurance.

Navigation & Export

Optimised field navigation paths for GCP placement crews. Unified KML export package compatible with DJI RC and field navigation apps.

Our Approach

Beyond the Brief — Intelligent Planning

Grid-based subdivision is a starting point, not a solution. Real survey areas are divided by fences, roads, and property boundaries that determine where you can actually fly and how you access the land. Our platform understands this.

Traditional Geometric Grid Overlay

Our Approach Cadastral-Aware

Land-Aware Subdivision

We integrate cadastral data, OpenStreetMap (roads, tracks, fence lines), and elevation data to subdivide along real-world features. Flight zones follow property boundaries — not arbitrary grid lines.

Integrated Project Costing

The tool doesn't just plan — it costs. Select a deliverable (raw imagery, orthomosaic, LiDAR, annotated maps), and the system calculates crew days, travel, accommodation, per diem, and processing to produce a complete project quote.

Real-World Navigation

A* pathfinding routes field operators along actual roads, through gates, and around obstacles. Not theoretical straight-line paths through fences — actual routes a crew would drive or walk, with terrain-aware time estimates.

Airspace Safety: All flight plans are overlaid against OpenAir Australian airspace data. The system flags restricted zones, controlled airspace, and height ceilings before a mission is finalised — keeping operations compliant without manual NOTAM checks.

Technical Architecture

Built for Performance & Scale

A cross-platform desktop application backed by a high-performance Rust API, with best-in-class web mapping libraries for the interactive GIS layer.

 Flutter Desktop Application Cross-platform UI — Windows, macOS, Web • Single codebase
 Interactive Map Engine (WebView) Mapbox GL JS + OpenLayers + Turf.js • Drag, rotate, resize, clip
 Rust Backend API High-performance geometry processing • Auth • Project management
 PostgreSQL + PostGIS Spatial database • Polygon operations • Spatial indexing
 Data Integration Layer State Cadastral WFS • OpenStreetMap • OpenAir • SRTM Elevation

Why This Stack?

 Flutter

Single codebase for Windows, macOS, and web. Future mobile apps (companion, DJI controller) come free. Proven in our prior GCS build — 35+ screens, cross-platform.

 Rust

Memory-safe, zero-cost abstractions, and extreme performance for geometry processing. Handles polygon clipping and spatial operations on multi-thousand hectare datasets without breaking a sweat.

 Web GIS

Mapbox GL JS and Turf.js are the industry standard for interactive geospatial applications. Embedded via WebView, giving us the full power of the web mapping ecosystem inside a native app shell.

Data Integration

Australia-Wide Data — Zero Licence Fees

Every data source in the MVP is publicly available at no cost. We integrate state government cadastral services, open mapping data, and aviation datasets to build a complete operational picture.

State Cadastral Services

Property boundaries from all 8 state/territory WFS APIs — NSW Spatial Services, QLD QSpatial, VIC DELWP, WA Landgate, SA DataSA, TAS LIST, NT Open Data, ACT ACTmapi.

OpenStreetMap

Roads, tracks, fence lines, gates, and land features via Overpass API. Community-maintained and continuously updated.

OpenAir Airspace

Australian controlled airspace, restricted zones, danger areas, and altitude ceilings. Visual overlay with automatic safety warnings.

SRTM / GA Elevation

Shuttle Radar Topography Mission and Geoscience Australia DEM data for terrain classification. Drives terrain-aware productivity rates in the costing engine.

Mapbox Satellite

High-resolution satellite imagery and vector map tiles for the interactive planning canvas. Free tier covers development; scalable pricing for production.

DJI Aircraft Database

Specifications for supported aircraft and payloads (M400, L3 LiDAR, RGB cameras, etc.). Battery capacity, flight endurance, and coverage rate parameters.
